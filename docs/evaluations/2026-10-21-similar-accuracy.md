## 원문 근거 분류와 응답시간 제한

모호한 비교 근거에만 모델 1회로 원문 문단 ID를 선택한다. 서버는 이슈 ID·문단 ID·원문 버전을 대조하고 조치와 완료 근거가 같은 노트/필드인지 검사한다. 모델이 새 문장을 생성하지 않는다. 불명확한 추정은 따로 표시하며 빈 모델 분류가 이미 확인된 본문 원인이나 명시적 완료 조치를 지우지 않도록 했다.

호출은 timeout 4초, 재시도 없음, 이슈당 문맥 2,400자, 출력 450토큰으로 제한했다. 모델·endpoint·전체 제공 근거 해시에 묶인 캐시는 TTL 300초·최대 64개이며 원문 변경 시 무효화한다. 실패 시 검증 가능한 기존 추출과 표시 경고로 돌아간다. 근거 선택의 의미적 적합성은 ID 검증만으로 보장되지 않는다.
