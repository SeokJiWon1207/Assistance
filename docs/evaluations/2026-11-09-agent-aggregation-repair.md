# 집계 보정 기준 누락 수정과 순차·병렬 재검증

기간 오류 보정에서 집계 기준이 사라졌던 직전 실패 2응답을 재현하고, 준비·실행 계약과 보정 안내를 수정했다. 동일 한투·KB·NH 12문항을 순차 1개/병렬 2개로 각각 3회, 총 72응답 실행했다. 집계 18/18과 이슈 건수·목록·후속이 모두 통과했다. 실제 기간 오류 보정 8건도 모두 그룹을 함께 복구했다. 복합 질문의 직접 근거 미확인 18응답은 부분 완료로 유지했다.

## 원인과 수정

- 복합 집계의 기간이 거절된 뒤 `aggregation=null`만 보정하면 그 안의 상태 그룹도 사라졌다. 기존 검증기는 `operation=aggregate, group_by=null, aggregation=null`을 받아들였고, 이후 집계 도구가 계약 불일치로 거절했다.
- 공통 집계 대상 검사를 준비 단계와 실행 직전에 연결했다. 단순 그룹도 계산 명세도 없는 집계는 확정하지 않는다. 거부한 변경은 원래 초안에 반영하지 않는다.
- 기간 없는 상태별 건수는 모델이 `changes={"aggregation":null,"group_by":"status"}`를 함께 제출하도록 안내한다. 서버가 날짜나 그룹을 임의 생성하지 않는다.
- 정상 단일 그룹, 기간·복합 그룹·공수 명세, 그룹 없는 유효 지표 합계는 유지한다. 기존 조건·원문 근거·수치 검증, 전송 마스킹·허용 모델·27개 이슈 승인 차단기는 변경하지 않았다.
- 직전 순차 2·3회차의 실제 확정 계획을 모델/네트워크 없이 재생했다. 수정 전 두 계획 모두 계약 통과, 수정 후 모두 집계 기준 누락으로 거절했다. `replayed-failures.json`에 보존한다.

## 비교 조건과 원본 변경

- 직전 기준선: [목록 조건·상세 대상 분리](2026-11-09-agent-followup-scope.md). 질문 12개, 반복 순서 S1/P1/P2/S2/S3/P3, 허용 모델과 평가 기준은 같다.
- 공유 작업 공간에서 별도로 개발 중인 추천 기능의 변경을 제외하기 위해 직전 고정 코드에 이번 집계 수정 4개 파일만 적용했다. 양쪽 방식은 동일 코드·설정·원본 저장본·가격표이며 동시 도구 수만 1/2다.
- 최신 원본 SQL에서 한투 5건·KB 8건·NH 14건과 최근 목록 ID·순서·정확한 제목, 승인된 전체 27개 ID가 동일함을 확인했다.
- **모델 실행 전 NH #30878의 실제 상태 변경(new → developed)을 확인했다.** NH 상태별 정답만 신규 1/개발완료 3에서 신규 0/개발완료 4로 사전 갱신했다. 다른 건수·목록·질문·관련성 판정·검증 기준은 그대로다. `oracle-drift.json`과 이전/현재 케이스를 보존한다.
- Notion 목록 TTL이나 수집 시각을 조작하지 않았다. 본문 읽기, 관련 참고 근거, 직접 기능 가이드 확보를 분리하고 미판정은 통과로 처리하지 않는다.
- 이번 결과는 집계 보정에 대한 회귀 비교다. 서로 다른 문항은 12개이며, 반복 72응답을 72개 독립 문항으로 보지 않는다.

## 호출·승인 범위·검증 기록

- 모델 호출 334회는 모두 Luna HTTP 200이었다. Gemini 대체는 없었다. 총 토큰 추정 비용은 **$0.104197145**다. 별도의 모델 시험 호출은 추가하지 않았다.
- 사용량·캐시 쓰기 미보고, 단가 미산정, 승인 범위 차단은 순차·병렬 모두 0회였다. 조건을 승인 ID에 맞춰 임의로 축소하지 않았다.
- 병렬 묶음 18개, 그 안의 도구 실행 36회를 확인했다. 실제 최대 동시 도구 수는 순차 1개·병렬 2개였다.
- 원천 429는 없었다. 순차 Notion 읽기 시간 초과 1회, 병렬 Notion 404 1회는 요청 수와 지연에 포함했다.
- 최종 조건·근거·수치 검사에서 실패 판정은 없었다. AI 서술의 `model_content_review=review` 29개/28개 표시는 유지했다. 이는 응답별 중복 검사를 포함하며 요청 전체 완료율과는 다른 지표다.
- 실제 18개 집계의 감사 기록을 재검사했다. `group_by=status`, 미해결 `open`, 전사 범위, 임의 기간/단건 ID 미삽입, 그룹 합계=전체 건수를 모두 확인했다. `aggregate-audit.json`에 기록했다.
