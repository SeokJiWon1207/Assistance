# 근거를 보존하는 짧은 답변과 제한된 추가 노트 조회

## 적용 범위

Open WebUI에서 참고한 답변 생성과 필요한 근거 보충의 책임 분리를 기존 이슈 설명 흐름에 맞춰 적용했다. 임의 도구를 반복 실행하는 에이전트 대신, 이미 검증한 검색 범위와 선택 이슈 안에서만 노트를 추가 조회한다.

첫 근거 선택 호출에서 질문 항목마다 짧은 답변 초안과 문단 ID를 함께 받는다. 서버가 실제 이슈·필드·노트·원문 문맥을 검증한 뒤, 기존의 두 번째 독립 검토 호출이 문장의 수치·함수·주체·조건과 원인·조치·완료 범위를 원문에 대조한다. 검토 결과를 다시 서버에서 검증하여 핵심 답변과 문장별 출처를 표시한다. 별도의 상시 요약 모델 호출은 추가하지 않았다.

요약은 항목당 최대 180자, 합계 520자, 최대 5개 항목이다. 프롬프트는 이보다 짧은 140자/480자를 목표로 한다. 선택 근거에 없는 수치·영문 식별자, 링크·HTML, 근거 없는 확정 완료 주장, 출처가 없는 사실 문장을 거부한다. 의역한 항목 이름은 질문 원문과 겹치는 구절만 보존하고, 겹치는 구절도 없으면 숨긴다. 고객 검증·운영 반영처럼 여러 미확정 항목이 같은 안내 문장으로만 표시되지 않도록 한다. 하나라도 검사를 통과하지 못하면 일부 답만 표시하지 않고 기존 원문 기반 답변 전체로 되돌린다. 출처 없는 미확정 답변은 서버의 고정 안내로 대체한다.

원문 인용과 전체 이력은 삭제하지 않는다. 화면은 핵심 답변을 먼저 표시하고 ‘원문 근거와 전체 이력 보기’에서 펼치도록 한다. HTML을 실행하지 않는 기존 문자 기반 렌더러에 맞춰 접기 기능을 연결했으며, 인용 안의 HTML·Markdown·다른 번호는 문자 그대로 보존한다.

## 추가 조사 조건과 한계

- 선택된 이슈의 원문이 부분 조회이고 답하지 못한 항목이 있거나, 마지막 상태·QC·전달 같은 이력 확인에 전체 노트가 필요한 경우에만 조회한다.
- 모델의 추가 조회 요청만으로는 충분한 답변의 재조회를 허용하지 않는다. 전체 원문에 없는 사실은 같은 자료를 재조회하지 않고 미확정으로 남긴다.
- 요청당 최대 1회, 최대 2개 선택 이슈이며, 추가 조회 전체에 8초의 협력적 실행 예산을 둔다. 상위 요청의 마감과 사용자 취소를 유지한다. 임의 웹 검색이나 다른 이슈 탐색은 실행하지 않는다.
- 기존 원천의 조건·접근 범위·소스 변경 검사와 안전 필터를 그대로 사용한다. 조회 실패는 부분 근거 사용을 알리고, 접근 제한·조건 불일치·원문 변경은 설명 확정을 보류한다.

서버 검사는 문장 전체의 의미가 참임을 수학적으로 증명하는 절차가 아니다. 출처 결속·형식·수치/식별자 존재·완료 단계의 보수적 검사와 독립 모델 검토를 결합한 것이다. 수치 사이의 관계, 부정의 범위, 한국어 의미까지 완전히 보장하지 않으므로 실제 최종 답변을 원천과 별도로 대조했다.

설정 예시의 `#8f897b`, `#385391`을 이슈 번호로 오인해 차단하는 기존 검증 문제도 수정했다. 실제 원문의 `color` 값에 있는 6자리 색상만 색상 문맥에서 ID 추출 대상에서 제외한다. 원문에 없는 색상, 명시적인 ‘이슈 #385391’, 색상 문맥이 없는 참조, 별도의 미지원 이슈 번호는 계속 검증한다. 제목·속성 값 자체는 바꾸지 않는다.

집계 계산, 인증 사용자 해석, 단일 질문 계획과 후속 조건 상속 코드는 이번에 수정하지 않았다. 이번 작업 시작 시점의 코드 사본과 비교한 backend 변경은 `evaluation/explanation_quotes.py`, 새 `evaluation/explanation_summary.py`, `evaluation/issue_facts.py`, `services/grounded_explanation.py`, 새 `services/explanation_investigation.py`, `static/modules/chat_source_quote.js`다. 이전 작업의 미커밋 변경은 기준 사본에도 포함해 보존했다.

## 제한 조회와 회귀 검증

일부 노트를 가린 두 통제 사례에서, 이전에는 모두 원문을 재조회했다. 변경 후에는 QC·전달 노트가 빠진 #31020만 1회 조회하여 541자를 보강했고, 답에 필요한 #31024의 기술 설명이 이미 있는 경우에는 조회하지 않았다. 복원한 QC 5/14·전달 5/15와 TR·주기 설명의 근거를 실제 원문에 대조했다. 각 응답은 계획·선택·독립 검토의 3호출이었고 추가 요약 호출은 없었다. 이 2사례를 일반적인 조회량 50% 절감으로 해석하지 않는다.

색상 회귀는 실제 회사 모델의 최종 질문·후속 질문 모두 차단 없이 응답했다. 설정 예시는 `customColorRanges`, 1–5 `#8f897b`, 6–12 `#385391`이며 고객 환경 검증 완료는 미확정으로 남겼다. 원문 색상 이외의 실제 이슈 번호 검사를 유지하는 부정 테스트도 통과했다.
