# P6 이후 최근 일주일 테스트 재실행

2026-10-26~11-02 기록에서 10/30의 고정 문항 17개·19턴을 찾아, P6까지 반영된 현재 코드와 실제 Luna로 다시 실행했다. 기존 문항 파일과 기대값을 그대로 사용했고 해시도 같다. 제품 코드는 수정하지 않았다.

결과와 원본 로그는 `assistant_web/runtime/weekly-regression-20261102-112814/`에 있다. 이 폴더는 실제 문서 내용이 포함된 Git 제외 검증 자료다.

10/30 전체 원측정은 15/17문항이었다. 당시 담당자 후속 대화만 별도로 보완·재검증해 문항별 검증을 합치면 16/17이었으나, 이번에는 17문항 전체를 한 번에 재실행했다. 문항·기대값은 유지했고, 기존 실패 문항도 빼거나 채점 기준을 바꾸지 않았다. 이 결과로 구조 개선이 모델의 정확도를 높였다고 단정하지 않는다.

본 실측의 OpenAI HTTP 요청 37개는 모두 200이었다. Luna 준비 요청·스트림 점검과 추가 계획 3개는 본 실측의 정확도·시간 집계와 구분했다. Gemini 준비 요청은 402였으며, 실제 Gemini 성공이나 실제 장애 시 대체 성공을 확인했다고 보지 않는다. 대체 정책의 결정형 테스트는 전체 회귀에 포함돼 통과했다.

## 한투 문서와 근거 설명 확인

한투 두 질문은 각각 문서 5개를 반환했고 기존 자동 채점에 모두 통과했다. 추가 원문 속성 검사는 **8/10**이었다. 나머지 2개는 별도 고객사 속성이 없는 버전처리 문서여서, 고객사 속성 또는 보고서의 `[한국투자증권]` 표식만 확인하던 기존 보조 검사로 판정되지 않았다. 그 실패 결과는 `customer-source-audit.json`에 그대로 남겼다.

별도 고객사 속성이 없는 2개 문서는 원문 제목의 정확한 회사명 표기를 GET으로 확인했다. 이 검토를 합치면 반환 문서 10개의 고객사 관련성을 확인할 수 있다. 별도 제목 검토는 원래 자동 속성 검사 점수와 합치지 않았다. 설명 4개도 인용된 원문과 대조해 최초 요청·후속 변경·계획·완료 수준을 확인했다. 실제 문서 제목과 이슈 식별자·원문은 Git 제외 검증 기록에 보관한다.

정확도 기준은 통과했지만 한투 검색의 지연은 남아 있다. 현재 두 번째 질문은 기존 180초 요청 예산에 가깝다. 추가로 시간을 늘리거나 검색 조건을 완화하지 않았다.

10/30 원천 저장본을 파일 복제로 격리했고 Notion·Mantis의 필요한 재검증은 현재 읽기 API로 수행했다. 따라서 저장본의 경과 시간·외부 문서·응답·모델 출력·캐시 조건이 원측정과 완전히 같지는 않다. 현재 원천 호출에는 429가 4번, 통신 예외가 10번 있었고, 소스의 정상 HTTP 응답은 2,127개였다. 이 한 번의 비교로 지연 증가를 P6 코드만의 영향으로 단정하지 않는다.

## 실행 범위와 보존

- 원천 DB는 `isolated-runtime/` 복제본, 감사·workspace·사용자 DB도 별도 경로를 사용했다. 운영 DB를 검증용으로 수정하지 않았다.
- 외부 요청은 모델·임베딩과 Notion/Mantis 읽기만 허용했다. Notion 생성·갱신, Mantis 변경 요청은 차단했다.
- 실제 채팅은 현재 `ChatService`와 기존 전체 단계·최종 검증·감사 저장 경로를 사용했다. 고정 응답으로 모델을 대체하지 않았다.
- 전체 회귀에는 최근의 삭제·복원·충돌·알림·집계·대기열·취소·필터·보안·프런트 모듈 테스트가 포함된다. 운영 서버의 장시간 동시 접속 부하나 수동 브라우저 전체 점검을 다시 수행한 결과는 아니다.
- 검증 시작·종료의 backend 파일 해시가 같음을 확인했다. 제품 수정·커밋·서버 재시작·배포는 수행하지 않았다.

핵심 파일은 `summary.json`, `report.json`, `report.md`, `responses.jsonl`, `latency-comparison.json`, `readiness.json`, `stream-readiness.json`, `planner-edges.json`, `customer-source-audit.json`, `manual-review.json`, `http-metadata.jsonl`, `full-check.log`다. 이전 문항 대비 채점과 실제 지연을 다시 검토할 수 있도록 모두 보관했다.
