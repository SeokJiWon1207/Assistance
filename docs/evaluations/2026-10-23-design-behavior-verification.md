# 디자인 변경 후 동작 검증

검증일: 2026-10-23. 대상: 현재 작업 디렉터리의 로컬 앱, Chrome의 팀원 계정. 제품 코드는 수정하지 않았다.

## 판정

최신 파일을 다시 로드한 상태에서 주요 사용자 동작의 새로운 회귀는 확인되지 않았다. 다만 검증 도중 로드된 중간 버전에서 질문 전송 오류를 한 번 재현했고, 기존 후속 질문 해석 오류도 재현했다. 따라서 모든 기능과 답변이 정상이라는 판정은 아니다.

### 발견 사항

1. **중간 버전의 질문 전송 오류**: 15:39 첫 전송에서 `renderProgressSteps is not defined`가 발생해 질문만 표시되고 요청이 진행되지 않았다. 검증 중 `chat.js`가 갱신됐으며, 15:39:18 저장된 파일에는 함수 정의가 존재한다. 새로고침 후 진행 단계·완료·중지·재생성이 정상 동작했고 이후 수집한 브라우저 오류/경고는 없었다. 이 검증에서 코드를 고친 것은 아니다. 기존에 열린 페이지도 최신 파일을 로드해야 한다.
2. **기존 후속 조건 오류**: 월간 미종료 고객사별 집계 후 “그중 미래에셋증권만 건수로 알려줘”는 `서로 다른 상태 계획 충돌`로 확인을 요구했다. 백엔드/의도 해석 파일은 직전 고객사명 검증본과 동일하다. 직전 검증에서도 고객사만 좁히는 후속 질문의 상태 경고가 존재했으므로 디자인 회귀로 분류하지 않았다. 실제 답변 오류로는 남아 있다.
3. **표 가독성 보완점**: 일반 Markdown 표의 이슈 ID가 `3166` / `8`처럼 줄바꿈된다. 데이터는 정확하지만 읽기 불편하다. 이번 검증만으로 디자인 변경 전후의 악화를 확정하지 않았으며 신규 회귀 건수에 포함하지 않았다.

## 실제 질문과 원본 대조

| 질문 | 실제 결과 | 서버 처리 시간 |
|---|---|---:|
| 이번 달 등록된 미종료 이슈를 고객사별로 요약해줘 | 38건, 18개 고객사, 검증 통과 | 7.08초 |
| 그중 미래에셋증권만 건수로 알려줘 | 상태 계획 충돌, 집계하지 않음 | 7.84초 |
| 이번 주 등록된 미종료 이슈를 고객사별로 요약해줘 | 중지 후 재생성 성공, 26건, 14개 고객사 | 8.36초 |
| 이번 달 미래에셋증권 MTS 미종료 이슈를 표로 모두 보여줘 | #31668·#31636의 2건, 검증 통과 | 6.05초 |

시간은 감사 기록의 `beforeFinalizationMs + verificationAndFormattingMs`이며 브라우저 렌더링 시간은 포함하지 않는다. 동일 질문 반복 비교를 수행하지 않았으므로 속도 개선/악화 판정에 사용하지 않는다.

원본 SQLite 저장본을 별도로 복사해 앱의 집계 함수 없이 팀 담당자 명단, 미종료 상태, 등록일, 고객사, 매체구분으로 계산했다. 월간 38건·주간 26건·미래에셋증권 MTS 2건과 대시보드 전체 78건·LS증권 13건이 일치했다. 원본 수집 시각은 15:48이며 앞선 두 답변은 15:38 저장본을 사용했다. 서로 다른 수집 시점이므로 완전히 동결된 전후 정확도 실험은 아니다.

## 검증 범위와 증거

검증 중 관리자 화면 CSS와 로그인 카드·관리자 생성 파라미터 표시도 추가 갱신됐다. 관련 diff를 확인하고 최종 자동 검사를 다시 실행했다. 현재 팀원 계정에는 관리자 화면 접근 권한이 없어 실제 관리자 UI는 검증하지 못했으며 로그인 양식 재제출도 하지 않았다. 다크 모드, 다른 브라우저, 실제 휴대전화 키보드, 운영 서버는 검증 범위 밖이다. 긴 대화는 기존 자동 회귀 검사로 확인했으며 이번 브라우저 확인은 일반 대화 복원이다. 운영 배포·커밋은 수행하지 않았다.

증거는 커밋 대상이 아닌 `assistant_web/runtime/design_verification_20261023/`에 보관했다:

- `browser_questions.json`: 실제 질문 4건의 답변·조건·근거·시간.
- `source.sqlite3`, `independent_counts.json`: 독립 집계에 사용한 저장본과 결과.
- `template-forms.json`: 12개 템플릿 입력 화면 확인 결과.
- `manifest.json`: 확인 시점 제품 파일 해시.
- `template-mobile.png`, `template-desktop-final.png`, `chat-tablet.png`, `dashboard-mobile.png`, `dashboard-desktop.png`, `source-detail.png`, `table-answer-top.png`: 실제 화면.
