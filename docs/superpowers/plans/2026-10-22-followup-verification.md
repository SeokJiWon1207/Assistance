# 후속 질문 자동검증 오탐 수정 계획

목표: 서버 감사 기록으로 복원한 후속 질문을 계획 생성과 최종 검증에 동일하게 사용한다.
감사 로그·후속 질문 표시에는 사용자가 입력한 원래 질문을 보존한다.

## 수정 범위

- `backend/services/chat_service.py`: 통합 계획 생성에 사용한 서버 문맥을 최종 검증에 전달한다.
- `backend/evaluation/finalization.py`: 검증용 문장을 명시적으로 받고 원래 질문과 분리한다.
- `tests/test_unified_accuracy_failures.py`: 실제 감사 기록 복원부터 최종 검증·로그 저장까지 회귀 검증한다.

## 회귀 검토 대상

- Notion 단일 제목을 참조한 후속 질문의 계획 검증이 통과해야 한다.
- Mantis 두 번째 이슈를 참조한 후속 질문의 계획 검증이 통과해야 한다.
- 응답의 조회 문장·계획에 다른 질문을 삽입해도 검증이 통과해서는 안 된다.
- 최종 감사 로그의 질문은 보강 전 사용자 입력이어야 한다.
- 이전 사용자의 감사 기록과 클라이언트가 꾸민 출처는 참조 근거로 인정하지 않는다.

## 실행

1. 회귀 테스트의 실패를 확인한다.
2. 검증용 문장 전달만 수정하고 회귀 테스트를 통과시킨다. 라우팅·필터는 변경하지 않는다.
3. 공식 `assistant_web/scripts/check.sh` 전체 단계와 변경 내용을 검토한다.
4. 한국어 커밋을 만들고 PR의 CI 통과 후 병합한다.
5. 운영 DB 백업·보안 사전 점검 후 코드 릴리스를 전환하고 동일 후속 질문을 실제 HTTPS API로 재검증한다.
