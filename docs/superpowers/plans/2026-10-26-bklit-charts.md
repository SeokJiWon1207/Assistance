# Bklit 업무 차트 적용 계획

**목표:** 사용자가 선택한 원본 Bklit 차트를 기존 FastAPI/일반 JS 화면의 차트 영역에만 적용한다.
**설계:** React 차트 번들을 로컬 빌드해 정적 파일로 제공한다. 공식 MIT 소스·커밋·해시와 의존성 잠금 파일을 보관한다. 서버는 Node를 실행하지 않는다. 기존 HTML은 로딩/실패 시 대체 표시와 키보드 동작을 유지한다.
**승인 범위:** 추천 순서대로 원본 컴포넌트 적용, 기존 기능·실제 데이터 유지, 검증. 커밋·배포는 이번 요청에 포함하지 않는다. 서브에이전트 사용 안 함.

## 순서와 수정 파일
- [x] 1. `frontend/` 원본·빌드 구성, `static/modules/bklit_charts.js`, `dashboard.js`: 고객사·경과·팀원 Bar + Tooltip + Legend. 기존 클릭/필터/상세 동작 보존.
- [x] 2. `backend/chart_data.py`, `workspace.py`, `workspace.js`: 담당자 범위 전체 원본에서 최근 7일 등록 추이 집계, Sparkline 연결.
- [x] 3. `reports/dashboard.py`, `frontend/src/`: 조회 기간의 일별 등록 추이와 Bklit Line/Brush. Brush는 신규 추이 내부 확대 범위이며 전체 미종료 지표의 의미를 변경하지 않음. 키보드 날짜 입력 제공.
- [x] 4. `frontend/src/`, `workspace.js`: 선택 기간 신규 이슈의 현재 상태 도넛(종료·미종료·미상 모두 포함), 내 업무 향후 28일 완료예정일 달력과 원문 연결. 등록일/마감일 기준 명시.
- [x] 5. `tests/`, `scripts/check.sh`: 범위·중복·날짜·일부 조회·0건·필터·마운트 해제 회귀 테스트, 빌드 재현성 검사. 실제 저장본 대조 및 브라우저 데스크톱/태블릿/모바일/다크·감소 모션 검증.

## 검증 기준
- 미종료 지연/장기 중복 집계 금지, 기간 신규 합계와 일별 합계 일치.
- 내 업무의 현재 미종료 목록으로 전체 등록 추이를 추정하지 않음.
- 일부 조회는 최소 건수·확인 범위를 표시하고 분모가 불완전한 비율은 숨김.
- 날짜 무효/범위 밖 제외, 미래 등록일 집계 제외, 마감 미등록은 별도 표시.
- 차트 실패 시 원래 수치·버튼 접근 가능; 탭/필터/갱신 시 이전 React 루트 해제.
- 사용자 변경 파일은 유지하고, 새로운 차트와 관련된 수정만 추가.

## 진행 기록
- 기존 CSS/SVG 차트와 데이터 흐름 확인 완료. 일반 구현 선택은 사전 지침에 따라 자율 결정.
- Bklit 공식 레지스트리의 Line Chart에는 문서에 있는 Brush가 빠져 있어 공식 저장소의 고정 커밋 원본으로 보완한다.
