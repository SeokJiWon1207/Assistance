# 미반영 작업 main 통합 계획

> 실행 방식: AGENTS.md에 따라 메인 에이전트가 직접 수행한다. 사용자는 모든 작업트리의 미커밋 변경까지 main 통합을 승인했고 운영 배포는 보류했다.

**목표:** 원본 작업트리의 변경을 보존하면서 현재 코드·테스트·문서와 로컬 main의 미전송 커밋을 원격 main에 통합한다.
**방식:** 원격 main에서 분기한 기존 격리 작업트리에 로컬 main을 병합하고, 별도 임시 Git 색인으로 수집한 패치를 3방향 적용한다. 공통 파일의 충돌은 Gemini·조회 검증과 각 작업의 회귀 테스트를 함께 보존해 해결한다.
**검증:** Python 3.12 가상환경과 assistant_web/scripts/check.sh의 tests compile shell ruff mypy audit 및 PR CI를 사용한다.

## 제한

- 운영 서버에 접속하거나 배포 스크립트를 실행하지 않는다.
- 원본 브랜치·작업 파일·색인을 변경하지 않는다.
- 비밀값·가상환경·node_modules·output 발표자료 생성물은 커밋하지 않는다.
- 서로 다른 목적의 변경은 별도 커밋으로 기록한다.
- CORS·인증·모델 endpoint 보안을 완화하지 않는다.

## 실행 단계

- [x] 원격 main의 전체 검사로 기준 상태를 확인한다.
- [x] 로컬 main의 고객사 약칭·Notion 최근 등록 조회 커밋 3개를 병합한다.
- [x] 기존 로컬 변경의 모델 대체 호출·Notion 검색 예산·Mac 터널 문서를 통합한다.
- [x] 메모리·검색 색인·프런트엔드 모델 준비·DB 백업 변경과 회귀 테스트를 통합한다.
- [x] 충돌·라우팅 회귀·검사 실패를 해결하고 전체 diff를 직접 검토한다.
- [x] 원본 파일 지문 보존과 비밀값 제외를 확인한다.
- [ ] PR을 만들고 CI 통과 후 main에 머지한다. 운영은 배포하지 않는다.

## 통합 검증 결과

- 전체 결정형 테스트 2,564개 통과, 커버리지 89%. compile·shell·ruff·mypy·audit 통과.
- 최근 문서 본문 검색 fixture의 누락된 외부 응답을 보완했다. 실제 네트워크는 계속 차단한다.
- 과거 기간 검색에 키워드를 함께 적용하는 main의 후속 수정을 보존했다. 오래된 메모리 작업 분기를 재적용하지 않는다.
- 메모리 스트리밍 회귀 7건을 추가하고 SQLite 연결의 명시적 종료를 유지했다.
- 원본 작업트리의 수집 대상 파일 61개는 SHA-256 대조 결과 모두 보존됐다. 비밀값 검사에서 탐지된 항목은 없다.
- 2026-10-12 검증 자료는 과거 작업의 기록이며 이번 통합에서 새로 운영을 배포했다는 의미가 아니다.
- 원격 main의 자동 실행은 CI뿐임을 확인했다. 운영 배포는 보류한다.
