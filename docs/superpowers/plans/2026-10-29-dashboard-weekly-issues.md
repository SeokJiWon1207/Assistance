# 금주 이슈 차트 구현 계획

사용자가 지정한 집계 기준과 Bklit 컴포넌트로 대시보드에 세 차트를 추가한다. 메인 에이전트가 직접 구현한다.

## 설계

- 기존 팀 담당 범위의 전체 데이터에서 집계한다. 7/14/30/90일 선택 및 목록 필터와 독립적이다.
- 한국 시간의 오늘이 속한 토~금(2022-01-01 기준)을 사용하며 금요일 전체를 포함한다.
- 접수: 고객사요청일. 완료: 고객사전달일, 제목의 정기점검 제외, 상태 무관.
- 잔여: 기간 무관, 종료된이슈·정보부족·개발완료·해결된이슈 제외. 기존 미종료의 정의는 유지한다.
- 접수/완료는 Bklit 가로 그룹 막대로 매체별 유형을 비교하고 잔여는 Bklit 도넛으로 매체 비중과 합계를 표시한다. 누적 막대보다 유형 간 비교가 쉬워 그룹 막대를 선택한다.
- HTS/MTS 외 매체와 미등록 유형도 누락 없이 표시한다. 일부 조회에서는 건수를 하한으로 표시하고 도넛 비율을 숨긴다.
- 날짜 누락/오류는 다른 날짜로 대체하지 않는다. 레거시 저장본도 실제 날짜 필드를 보존한다.
- 기본 HTML 수치 표, 툴팁, 키보드 범례, 모바일 세로 배치를 제공한다.

## 검토 중점

금요일 미래 입력 날짜도 주 안이면 포함, 연도 전환, 없는 날짜로 0건 단정 금지, 네 제외 상태의 영문/한글 일치, HTML 이스케이프와 부분 조회 비율 미표시.
