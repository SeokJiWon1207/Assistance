# 채팅 답변의 핵심 우선 표시

**Goal:** 결론·요약과 주요 결과는 먼저 읽고 긴 설명·관련 자료는 펼쳐 읽는다.
**Spec:** 사용자가 요청한 채팅 UI 개선. 답변 내용을 새로 요약하거나 수정하지 않고 기존 DOM을 재배치한다.
**Architecture:** 완료된 답변에만 공용 disclosure 모듈을 적용한다. 명시된 요약/결론을 앞에 두고, 긴 일반 답변은 문단·제목 경계에서 접는다. 표·주요 결과·불완전 조회 안내는 유지한다. 추이/순위 차트는 설명보다 앞에 두고 기존 공수 리포트의 원문 접기는 유지한다.
**Constraints:** 저장·복사·후속 질문의 원문 불변. 스트리밍 중 접기 없음. 새 라이브러리 및 모델 호출 없음. 메인 에이전트 직접 수행, 커밋 없음.

- [x] 짧은 답변·긴 답변·명시적 요약·조회 한계·표·원문 노드 보존 회귀 검사.
- [x] 완료 답변의 상세 설명/관련 자료 접기, 펼침 상태 재렌더 시 유지.
- [x] 차트 우선 배치 및 A/B 답변에도 같은 처리 적용.
- [x] 기존 검색 조건·복사·출처·기존 원문 접기 보존 확인.
- [x] 전체 검사와 실제 저장된 답변의 데스크톱·모바일 확인.

단일 긴 문단이나 주요 표 자체는 임의로 잘라 의미를 바꾸지 않는다. 접을 경계가 없으면 원래대로 표시한다.

## 검증 결과

`assistant_web/scripts/check.sh tests compile ruff mypy`: 2,630개 검사 통과, 커버리지 기준 충족, 컴파일·Ruff·mypy 통과. 실제 저장된 월별 추이 대화에서 차트 우선 표시, 키보드 펼치기/접기, 관련 자료 표 전환, 접힌 상세 내용의 전체 복사를 확인했다. 390px 모바일에서 disclosure가 화면 너비 안에 들어오는 것을 확인했다.
