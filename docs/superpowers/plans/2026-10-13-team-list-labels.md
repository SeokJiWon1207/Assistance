# 이슈 목록 한글 라벨과 기본 팀 범위 구현 계획

**Goal:** 상태·중요도에 원본 한글 label을 표시하고 일반 Mantis 조회 및 전체 목록을 팀 명단으로 제한한다.

**Architecture:** 내부 검색 코드는 유지하고 별도 표시 라벨을 원본→저장본→응답→표까지 전달한다. 검색 조건을 만드는 공통 경계에서 기본 팀 범위를 적용하며 명시적 개인·번호·전사 조회와 Notion은 기존 의미를 유지한다.

**Tech Stack:** Python, unittest, JavaScript, node:test.

**Spec:** 이 대화의 사용자 요청과 앞선 원인 조사.

## 제약과 검토 항목

- 초기 구현 단계에서는 기존 미커밋 변경을 보존하고 현재 작업 디렉터리에서 수정했다. 이후 사용자의 추가 요청에 따라 운영 배포와 작업별 커밋까지 진행했다.
- 팀 명단은 team_dashboard.json의 13명으로 재사용한다.
- 일반 목록·전체 목록·집계·후속 질문의 팀 범위가 일치해야 한다.
- Notion과 개인 조회에 기본 팀 조건이 간섭하지 않아야 한다.
- 원본 label을 우선하고 과거 데이터의 label 누락에는 기존 상태 변환을 사용한다.
- priority와 severity를 서로 대체하지 않는다.
