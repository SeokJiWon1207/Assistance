# 단계별 도구 조건 검증

요청: 모델이 각 조회 단계의 조건을 도구 인자로 정하되 기존 조건 근거·수치·출처 검증을 유지한다. 같은 한투 복합 질문과 상태별/기간별 집계 질문을 이전 단계 코드와 비교한다.

## 설계

- 요청의 답변 범위와 추가 조사 범위를 구분한다. 질문·인증·감사로 검증한 필수 조건은 모든 Mantis 단계에 유지한다. 도구 인자로 더 좁은 조건을 지정할 수 있으며 질문 구절이나 이번 요청에서 실제 읽은 구조화 필드로 근거를 검사한다.
- 조건 참조는 요청·원천·조건·용도에 결속한다. 추가 조사 결과는 원래 요청의 건수·순서·집계를 대체하지 않는다. Notion 공통 참고 검색의 조건 미적용 등급을 유지한다.
- 저장본 캐시는 실제 조건·정렬·표시 개수·집계 기준별로 분리한다. 상세 조회도 현재 단계 조건을 적용하며 다른 조건에서 얻은 캐시를 무조건 재사용하지 않는다.
- 도구별 적용 조건·근거·조회 완전성을 감사에 남긴다. 허위 근거, 조건 누락, 다른 원천 참조, 부분 조회의 0건 확정은 차단한다.
- 권한·외부 전송·원문 사실·수치 검증을 완화하지 않는다. 독립적인 여러 모집단을 한 답변의 총건수로 합치는 기능은 포함하지 않는다.
