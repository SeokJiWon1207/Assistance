# 조건 기반 이슈 문서의 에이전트 처리

사용자가 제시하고 선택한 B안에 따라, 문서 종류는 출력 목적을 나타내고 조회 순서는 모델이 결정한다. 스크린샷의 `화면번호 0000 최근 8주 이슈를 개발팀에 전달할 수 있게 증상·고객사·재현 조건 중심으로 요약해줘`를 회귀 사례로 사용한다.

## 설계

- 허용 모델·도구 검증·원천 설정을 통과한 `report/handoff`, `report/postmortem`, `report/notice`를 결정형 보고서 실행보다 먼저 에이전트에 전달한다. 그 외 보고서와 기능 비활성 상태의 기존 동작은 유지한다.
- 에이전트가 기존 건수·목록 도구와 상세 조회 도구를 사용한다. 조건 계약과 질문 근거 검증은 그대로 적용한다. 표시 건수를 명시하지 않은 문서 요청은 최대 20개 후보를 제공하되, 실제 읽은 범위와 전체 건수를 구분한다.
- 목록 조회만으로 최종 응답을 끝내지 않는다. 원문을 읽은 이슈만 문서의 사실 근거로 사용하고, 문장별 문단 ID와 이슈 ID를 대조한다. 별도 모델 검토와 기존 수치·완료 상태·고객용 정보 검증을 적용한다.
- 전체 조회 0건, 조회 미완료, 본문 일부 확보, 문장 검증 실패를 구분한다. 문서 검토용 호출·시간 예약은 목록 도구를 사용해도 유지한다.
- 고객 안내문에는 내부 번호·담당자·코드·출처 표기를 본문에 넣지 않는다. 출처는 별도 응답 메타로 유지한다.

## 작업

1. 차단 경로 및 조건 보존 회귀 테스트를 먼저 추가한다.
2. 문서 작업의 에이전트 우선 진입, 조회 도구 연결, 상세 읽기 기록을 구현한다.
3. 복수 이슈의 근거 결속 문서 생성·검토와 범위 표시를 구현한다.
4. 완전한 0건·미완료·원문 누락·이슈 간 근거 혼입·고객 정보 노출·모델 정책 회귀를 검증한다.
5. 관련 테스트 및 정적 검사 후 실제 저장본과 허용 모델로 같은 질문을 반복 검증한다. 검증 결과와 적용 범위를 문서화한다.

모든 작업은 메인 에이전트가 수행한다. 이번 요청에서 커밋·운영 서버 재시작은 수행하지 않는다.

## 거절 문장 보완 (2026-11-06)

사용자가 `#31505` 요약과 `#31699` 재현 조건을 같은 질문으로 다시 검증하도록 요청했다.
기존 승인된 17건과 모델 전송 범위를 유지한다.

- 기존 초안·인용 문단·검토 응답을 대조하고 정적 거절과 모델 거절을 구분한다.
- 판정 기준은 유지하면서 거절 사유를 보정에 전달하고, 항목 단위로 보정해 이미 검증된 문장을 보존한다.
- 거절된 항목을 생략해 완료로 처리하는 경우와 고객사 메타데이터를 발신 주체로 쓰는 경우를 회귀로 막는다.
- 동일 질문의 실제 모델 실행, 요청·확인 중을 완료로 바꾼 대조 문장, 기존 정적 판정의 일치 여부를 검사한다.

## 반복 조회와 의존성 감사 보완 (2026-11-06)

사용자가 남은 작업의 1번(반복 조회·호출 예산)과 2번(의존성 감사 실패 해결)을 선택했다.

- 완전한 Mantis 조건 조회와 표시 대상 본문 확보가 끝나면 작성·독립 검토 단계로 전환한다.
  조회·본문 미완료와 복합 원천 요청은 조기 종료하지 않는다. 같은 질문·17건으로 호출 수와 완료 판정을 비교한다.
- 보안 제약과 운영·개발 잠금의 `oauthlib`만 공식 패치 4.0.1로 갱신하고 가상환경에 설치한다.
  의존성 호환성 및 기존 감사 절차를 실행한다. 보안 예외·인증 정책은 변경하지 않는다.

## 문서 작성 반복 검증 확대 (2026-11-06)

사용자가 남은 작업의 3번을 선택했다. 인수인계·사후 분석·고객 안내를 같은 기준으로 검사한다.

- 결정형 회귀: 전체 조회 0건, 미완료 0건, 일부 후보만 조회, 본문 미완료,
  합성 250건 중 표시 대상 20건 읽기를 각 문서 유형에서 3회 반복한다.
- 실제 감사 기록으로 후속 요청을 연결한다. 문서 종류 변경·조건 상속·원문 재조회,
  현재 조회 중단 시 과거 요약 재사용 금지, 표시된 두 번째 이슈 선택을 검증한다.
- 세 유형 모두 근거 없는 숫자·완료 표현과 독립 의미 검토에서 거절된 문장을 차단한다.
- 실제 모델은 각 유형과 여섯 시나리오를 2회 실행한다. 0건은 원본 저장본의 실제 제목 필터,
  부분 조회는 원천 경계의 명시적 장애 주입, 대량 결과는 합성 자료, 후속은 승인된 17건으로 구분한다.
  기준일과 목록은 이전 재검증의 2026-11-05 저장본을 사용하며 운영 최신성 검증으로 표현하지 않는다.
- 문장 검증·전송 정책·호출 한도를 유지한다. 실패 실행도 결과에 남기고 원인과 재실행 버전을 구분한다.

검증 완료: 자동 회귀 3,121건과 정적 검사 통과. 실제 모델 36개 조합 중 24개 성공,
조회 범위·완전성 표시는 36개 모두 기대와 일치했다. 사후 분석 출력 잘림, 고객 안내 보정 실패,
미완료 본문 반복 조회는 `docs/evaluations/2026-11-06-agent-document-matrix.md`에 재현 결과와 다음 수정 순서를 기록했다.
