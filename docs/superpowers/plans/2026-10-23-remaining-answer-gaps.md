# 남은 답변 오류와 문서 지연 보완

- 기준: `codex/review-four-fixes`의 기존 미커밋 수정 전체를 보존한다. 집계 계산과 대화 보관 계약은 변경하지 않는다.
- 재현: 비교 종료 후 상태 전환 1건, 설명 메일 회신 판정 1건, 최신 고객 이력의 인수인계 반영 2건, 기술 조치와 QC·전달의 분리 2건.
- 구현: 검색 조건과 과업 전환 계약을 구분하고, 실제 발신된 회신과 수정본 전달을 분리한다. 인수인계 핵심에 최신 미해결 이력을 근거와 함께 반영한다. 기술 조치는 진행 단계와 별도로 추출한다.
- 성능: 문서 후속 질문의 계획 재시도 원인을 기록하고, 검증 범위를 줄이지 않으면서 첫 계획의 성공률을 개선한다.
- 회귀: 요청·수신·초안·타 이슈를 완료로 올리지 않는 음성 사례, 이전 집계·조건 및 164개 메시지 보존을 확인한다.
- 독립 검증: 구현 전에 새 질문 20개를 동결했다. 변경 전후 같은 원천 세대와 모델로 최종 답변·출처·응답시간을 비교한다. 개발에 사용한 기존 질문과 별도로 판정한다.
- 완료 기준: 전체 필수 검사와 실제 모델 검증 결과를 기록한다. 커밋·푸시·운영 배포는 이번 요청에 포함되지 않는다.

- 기존 미흡 4건·부분 충족 2건을 포함한 10턴을 최종본으로 재실행했고 6건 모두 충족했다.
