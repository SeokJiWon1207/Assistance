# 팀 대시보드 첫 진입 차트 표시 복구

사용자 증상은 첫 진입 시 차트가 보이지 않는 경우다. 현재 운영 오류 로그·기간 변경·700px 폭에서는 재현되지 않았고, 정적 파일 캐시는 no-store다. 분리한 실제 React 테스트 화면에서는 초기 모듈 요청 503 후 자동 재시도 없음, 복구 뒤 오류 표기 잔류, 표시 후 오류 발생 시 닫힌 대체 수치표가 숨겨지는 경로를 재현했다. 운영에서 같은 요청 실패가 일어났다는 증거와는 구분한다.

범위: 초기 동적 모듈 로딩을 한 번만 재시도한다. 실패한 차트의 수치를 다시 펼치고, 개별 차트 파싱·동기 마운트 실패가 다른 차트를 막지 않게 한다. 성공 시 오류 표기를 지운다. 데이터 집계와 공급업체 원본, 의존성, 보안 설정은 바꾸지 않는다.

- [x] 초기 일시 실패·계속 실패·개별 차트 실패·오류 표기 해제의 회귀 테스트를 추가하고 수정 전 실패를 확인한다.
- [x] `bklit_charts.js` 로더와 `charts.tsx` 오류 경계를 수정하고 배포 번들을 재생성한다.
- [x] 대상 Node 검사, 전체 `check.sh tests compile shell ruff mypy`, 실제 브라우저의 최초 503 자동 복구와 React 오류 후 수치 표시를 검증한다.
- [x] 현재 운영 릴리스와 대상 파일을 대조한 후 이번 변경만 새 릴리스에 반영하고 health/ready·첫 진입·기간 변경을 확인한다.
- [x] 임시 화면 크기를 원복하고 테스트 서버를 종료한다. 기존 변경을 보존하고 결과를 기록한다.
