# 집계 보정의 기준 보존 구현 계획

> 메인 에이전트가 executing-plans 절차로 직접 수행한다. 사용자 요청 없이 위임하지 않는다.

**Goal:** 기간 오류 보정에서 집계 명세와 단순 그룹이 모두 사라진 계획을 확정하지 않고, 같은 승인 범위의 순차·병렬 72응답을 다시 비교한다.

**Architecture:** 모델이 계획과 보정 인자를 정한다. 공통 집계 계약은 준비 단계와 실행 경계에서 필요한 집계 기준의 존재를 검증한다. 기간 없는 단일 그룹 건수로 전환할 때는 모델이 `aggregation=null`과 해당 `group_by`를 한 번의 변경으로 제출하도록 안내한다.

**Tech Stack:** Python 3.12, unittest, 기존 에이전트·벤치마크.

**Spec:** 사용자의 현재 요청 및 `docs/evaluations/2026-11-09-agent-followup-scope.md`의 집계 실패 2건.

## 제약과 검토 범위

- 조건·원문 근거·수치 검증, 27개 이슈 승인 범위 차단과 기존 마스킹/모델 허용 목록을 그대로 유지한다.
- 기간 없는 건수에 날짜를 생성하지 않는다. 정상 단일 그룹, 복합 그룹·공수·기간·비교 계약을 유지한다.
- 거부한 부분 변경이 원래 초안의 상태·고객사·범위를 바꾸지 않아야 한다.
- 준비 단계 이후 변조되거나 오래된 빈 집계 계획도 실행 경계에서 거절한다.
- 일반 총 건수, 그룹 없는 유효 지표 합계, 비교 범위별 집계에 영향을 주지 않는다.
- 부분 응답/직접 가이드 미확인과 비용·지연 실패를 성공으로 바꾸지 않는다. 운영 설정 변경·배포·커밋은 하지 않는다.

## 실행 전 확인된 원본 변경

같은 승인 27건의 ID·전체 건수·목록·제목은 유지됐다. NH #30878의 원본 상태가 신규에서 개발완료로 바뀌어 모델 실행 전에 상태별 정답만 수정했다. `oracle-drift.json`에 이전/현재 정답과 사전 등록 사실을 기록한다. 질문·검증 기준은 동일하며, 모든 반복은 같은 저장본과 이 정답으로 비교한다.
