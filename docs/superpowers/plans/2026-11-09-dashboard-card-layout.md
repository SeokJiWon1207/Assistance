# 팀 현황과 내 업무 카드 개선 구현 계획

> **For agentic workers:** `superpowers:executing-plans`로 직접 구현한다. AGENTS.md에 따라 서브에이전트는 사용하지 않는다.

**Goal:** 우선 확인할 이슈를 먼저 보여 주고, 담당 업무가 없을 때 중복된 빈 분석 카드를 줄이며, 내 업무와 팀 대시보드의 카드 스타일을 통일한다.

**Architecture:** 기존 문자열 렌더러와 CSS 토큰을 유지한다. 팀 현황은 기존 카드의 순서를 바꾸고, 빈 내 업무는 기존 브리핑·활동 렌더러를 재사용한다. 공통 카드는 현재 마지막 테마 계층인 `snow_theme.css`에서 조정한다.

**Tech Stack:** 기존 ES 모듈, CSS, Node 내장 테스트, Ego Lite.

**Spec:** 이 채팅에서 승인된 1차 개선안과 아래 범위. 사용자가 구현을 승인했으므로 추가 승인 없이 진행한다.

## 범위와 제약

- 팀 현황: 핵심 지표 → 우선 확인 이슈 → 신규 등록·고객사 비교 → 팀원·미종료 분포.
- 빈 내 업무: 단일 안내와 주간 브리핑·최근 활동. 의미 있는 과거 등록 추이는 유지한다.
- 전체 조회 완료·부분 조회·담당자 미연결·오류·필터 결과 없음은 구분한다.
- 중립적인 카드, 얇은 경계, 16px 모서리, 의미에 따른 위험 색상, 라이트·다크 대응.
- 기존 이슈 상세·필터·보고서 동작 및 오른쪽 패널 열기 설정을 유지한다.
- TDS 및 새 의존성 없이 현재 구조에 적용한다. 관련 없는 사용자 변경은 수정·커밋하지 않는다.

## 검토할 조건

- 실제 업무가 있지만 목표일 필터 결과가 0건이면 전체 업무 없음으로 전환하지 않는다.
- 일부 조회와 담당자 미연결은 업무가 없다고 단정하지 않는다.
- 빈 업무에서도 새 노트·배정 알림과 주간 보고 진입이 유지된다.
- 좁은 화면과 상세 패널을 연 화면에서 카드·표가 바깥으로 넘치지 않는다.
- 다크 모드에서도 지표와 경고가 읽히고, 위험 0건은 경고 색을 쓰지 않는다.
