# 요약 우선 대화 답변 UI 구현 계획

사용자가 선택한 ‘요약 우선’ 시안을 메인 에이전트가 직접 구현한다. 서브에이전트와 커밋은 요청되지 않았다.

**목표:** 답변의 결론과 실제 수치를 먼저 보여주고, 이슈 목록과 근거를 TDS 스타일로 읽기 쉽게 정리한다.

**설계:** 기존 답변 렌더러 다음에 표시 전용 모듈을 적용한다. 원문·복사·출처 식별자와 기존 차트는 유지한다. 실제 답변에 명시된 수치만 강조하고 새 합계나 해석을 만들지 않는다.

**시안:** `/Users/seokjiwon/.codex/visualizations/2026/11/08/01a1bd92-0fb9-7310-99fd-5d41375365f5/tds-answer-preview.html`의 ‘요약 우선’.

## 구현

- [x] `modules/answer_summary.js`: 명시적인 수치 행 파싱, 요약 제목과 대표 문단 강조, 이슈 표의 읽기 쉬운 행 보기, 근거와 조회 기준 정리.
- [x] `modules/chat_rendering.js`: 결정형 보고서의 독립된 섹션 제목 인식. 원문 인용은 건드리지 않는다.
- [x] `modules/chat.js`: 완료된 답변에 표시 모듈 연결, AI 비서 머리글 추가. 스트리밍·차트·A/B 경로를 보존한다.
- [x] `answer_summary.css`, `index.html`: 대화 영역만 적용하는 색상·글자·간격·반응형 스타일.
- [x] `frontend_answer_summary.test.cjs`: 날짜와 이슈 번호 오인 방지, 0건·천 단위·부분 조회 문구 보존, HTML을 텍스트로 처리 검증. 저장 원문과 출처 연결은 실제 브라우저 DOM에서 추가 검증.

## 검증

- 새 동작의 실패 테스트를 먼저 실행하고 구현 후 재실행한다.
- `node --experimental-vm-modules --test assistant_web/tests/frontend*.test.cjs`와 관련 정적 검사를 실행한다.
- `assistant_web/scripts/check.sh tests compile ruff`를 실행한다.
- 에고라이트에서 기존 답변, 대표 보고서, 근거 펼침, 출처 열기, 좁은 화면·어두운 테마를 확인한다.

## 검토 초점

- 수치가 없는 답변이나 조회 실패에 임의 지표를 만들지 않는다.
- 수치 뒤의 기간·하한·제외 조건을 빠뜨리지 않는다.
- 근거·원문 인용 안의 숫자를 요약 수치로 승격하지 않는다.
- 조회 범위와 검증 경고는 접힌 근거 안에 숨기지 않는다.
- 목록 전환 후에도 원래 출처 버튼과 전체 항목 표를 사용할 수 있다.

## 검증 결과

- 프런트엔드 292개 테스트 통과. 전체 결정형 테스트 3,284개 통과, 커버리지 91%, 컴파일·프런트엔드 빌드 검사·ruff 통과.
- 실제 브라우저 DOM의 원문 보존, 수치 범위, 인용 제외, HTML 비실행, 출처 키, 전체 표, 경고 노출, 펼침 상태, 스트리밍 보존 등 10개 확인 통과.
- 에고라이트에서 저장된 월간 보고서의 실제 수치와 이슈 상세 연결 확인. 390px 모바일·어두운 테마 가로 넘침 없음. 기존 공수 저장본의 집계와 일별 데이터 없음 안내 유지.
- 직접 검토 중 발견한 이슈 상세 이벤트 연결과 저장소 TDS 크기·굵기·모서리 규격 차이를 수정하고 전체 검사를 재실행했다.
