# 고객사 표시명 누락 보완

- 기존 고객사 이름표를 답변·출처·대시보드·개인 업무·브리핑의 표시 경로에 연결한다.
- 원본 project·집계 키·차트 필터 키·검색 질문은 유지한다. 같은 표시명의 별개 프로젝트를 합치지 않는다.
- 서버는 표시 메타데이터를 추가하고, 브라우저는 동일 이름표로 과거 저장 대화와 출처도 표시한다. 본문 원문 인용·기술 코드·미등록 프로젝트는 보존한다.
- 표시/식별자 분리 회귀 테스트부터 재현하고 수정 후 실행한다.
- 수정 전에 고정한 새 질문 8턴을 같은 원천·모델로 전후 실행하고 조건·건수·출처·응답시간을 비교한다.
- 실제 로컬 화면에서 차트·클릭 필터·업무 상세·질문 응답·출처 상세를 확인한다. 운영 배포는 이번 요청에 포함되지 않는다.
