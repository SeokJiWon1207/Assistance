# 재현 문제 네 가지 수정 계획

**목표:** 긴 근거·비교 후속·긴 대화 보관·문서 선택값을 보완하고 집계·조건 계약을 유지한다.
**승인 근거:** 직전 검토의 네 가지 개선안에 대한 사용자의 수정·새 질문 검증 요청.
**실행:** AGENTS.md에 따라 메인 에이전트가 직접 수행한다. 커밋·운영 배포는 이번 범위에 포함하지 않는다.
**구조:** 기존 검색과 집계는 유지한다. 긴 문단은 출처가 연결된 작은 근거로 분할한다. 작업 유지가 명시된 후속만 작업 전환을 거절한다. 대화는 사용자·대화·순번별 메시지로 저장하고 작은 요청으로 동기화하며 이전 기록을 페이지로 읽는다. 문서 형식은 검증된 사실의 표현만 바꾼다.

## 제약과 검토 초점

- Python 3.12, 새 외부 의존성 없음. 회사 모델 전송은 사전 승인 범위 내에서 수행한다.
- 결정형 집계와 포함·제외·기간·담당자 조건을 변경하지 않는다.
- 인증·쿠키·CORS·저장 요청 크기와 사용자별 저장 용량 보호를 유지한다.
- 긴 문단의 앞/중간/끝 근거, 실험·추정과 확정 진단의 경계를 검사한다.
- 명시적인 새 검색·이슈 상세 요청은 허용하고 조건 변경만 요청한 비교는 유지한다.
- 기존 DB 이관·동시 기기 충돌·과거 메시지 편집·연결 중단·개인정보 경계를 검사한다.
- 요약·채널·말투·대상을 반영하되 없는 원인·완료·안내 일정을 만들지 않는다.
