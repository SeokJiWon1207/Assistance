# 내 업무 이슈 상세 통일

**Goal:** 내 업무의 이슈 제목·달력에서 현재 화면을 유지하며 대시보드와 동일한 상세 패널을 연다.
**Spec:** 사용자가 지정한 기존 대시보드 상세 디자인과 동작을 재사용한다. 새 디자인·별도 원문 창으로 대체하지 않는다.
**Architecture:** 기존 패널 DOM과 렌더러를 공용으로 사용하고, 호출 화면별 목록·포커스·여백만 전달한다. 개인 업무의 위험 근거는 대시보드의 서버 집계 함수를 재사용한다.
**Constraints:** 메인 에이전트 직접 수행. 기존 변경 유지. 별도 의존성·API·커밋 없음. AI 요약은 별도 명시적 버튼으로 유지.

## 작업
- [x] 개인 업무 목록·주간 보고·달력 클릭과 동일 패널 연결. 내 업무 정렬 순서로 이전/다음 이동.
- [x] 화면·탭 전환 시 패널 닫기, Escape·포커스 복귀, 모바일 포커스 제한 유지.
- [x] 개인 업무에 동일한 위험 근거 제공. 종료·미상 이슈에 위험 상태를 만들어 붙이지 않기.
- [x] 제목 클릭, 정렬, 대시보드 미조회 상태, 종료·누락 데이터 회귀 검사.
- [x] `check.sh tests compile ruff mypy`, 실제 데스크톱·모바일 확인, diff 직접 검토.

## 확인할 경계
- 내 업무를 먼저 연 사용자도 팀 대시보드 조회 없이 상세를 연다.
- 주간 보고의 종료 이슈에 미종료 위험 표시를 붙이지 않는다.
- 목록 정렬·더보기 및 내/팀 보고 전환 후 이전/다음 대상이 섞이지 않는다.
- 닫힌 화면에 남은 패널이나 포커스 제한이 다른 화면을 가리지 않는다.
- 이슈 제목·근거 텍스트의 HTML은 실행하지 않는다.

## 검증 결과
- 최종 전체 검사: 2,630개 테스트 성공, 커버리지 90%, TypeScript·번들 일치·Python 컴파일·Ruff·mypy 통과.
- 중간 검사에서 별도 검색 정확도 작업의 테스트 6건 실패를 확인했으며, 해당 파일은 수정하지 않았다. 최종 재실행에서는 모두 통과했다.
- 브라우저: 개인 목록 및 달력 → 같은 상세 → 원문 보기, 주간 보고 종료 이슈 → 위험 근거 없음 → 다음 이슈, 탭·화면 이동 시 패널 닫힘 확인.
- 모바일 390px: Escape 복귀, 마지막 버튼에서 Tab을 누르면 닫기 버튼으로 포커스 순환 확인. 데스크톱 크기로 복귀했다.
