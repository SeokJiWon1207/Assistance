# 배포본·백업 자동 보관 계획

사용자가 지정한 현재 배포본과 직전 2개 버전을 유지하는 운영 정책을 구현한다. 서브에이전트 없이 직접 수행한다.

- [x] 실제 임시 파일시스템에서 보존·삭제·참조·잠금·비정상 상태 회귀 테스트를 먼저 작성하고 실패 확인.
- [x] 표준 라이브러리 기반 정리 도구 구현. 기본은 미리보기, 실제 실행은 명시적 --apply. 현재 및 직전 2개 완성 릴리스와 더 새로운 릴리스, 실행 프로세스·심볼릭 링크가 참조하는 항목 보존. 스냅샷은 정리 범위에서 제외.
- [x] 버전과 연결된 오래된 배포 백업 정리. 날짜로만 구분되는 예전 DB 백업은 최신 3개 묶음 및 7일 유예 보존. 모르는 이름·심볼릭 링크 루트는 건드리지 않음.
- [x] 운영 readiness 확인, 배포·롤백과 동일한 호스트 잠금, 계획 재검사 및 실행 기록 적용.
- [x] 배포 기본 보관 수를 총 3개로 변경. 성공 확인 후에만 기존 위험한 직접 삭제를 새 도구로 교체. 별도 systemd 일일 타이머도 설치해 수동 배포 경로의 누적 방지.
- [x] check.sh 검사, 운영 미리보기 비교 후 설치·실행·반복 실행·타이머·서비스 상태 확인. 현재 앱과 사용자의 별도 기능 변경은 재배포하지 않음.
