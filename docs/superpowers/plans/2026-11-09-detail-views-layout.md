# 고객사 상세와 이슈 상세 화면 개선 계획

> **For agentic workers:** `superpowers:executing-plans`로 직접 수행한다. AGENTS.md에 따라 서브에이전트를 사용하지 않는다.

**Goal:** 앞서 승인한 중립 카드·정보 위계를 고객사 상세, 이슈 옆 패널, 원문 보기 창에 확장한다.

**Architecture:** 기존 문자열 렌더러·DOM 원문 렌더러·이벤트와 대화상자 포커스 처리를 유지한다. 고객사 CSS를 범위 안에서 확장하고, 이슈 상세 전용 CSS를 추가한다.

**Tech Stack:** 기존 JavaScript·CSS·Node 테스트·Ego Lite. TDS와 추가 의존성 없음.

**Spec:** 기존 팀 현황·이슈·고객사·공수·화면번호에 적용한 디자인을 상세 화면에도 확장하라는 사용자 요청.

## 범위와 제약

- 고객사: 분리된 5개 지표 카드, 간결한 상태 근거, 미종료 목록을 분석보다 먼저 배치한다. 5건 미리보기와 기존 펼치기·정렬을 유지한다.
- 고객사 빈 결과와 부분 조회를 구분하며, 과거 활동이 있는 월별 차트는 유지한다.
- 이슈 옆 패널: 제목 → 권장 행동 → 기본 정보 → 판단 근거 순으로, 회색 바탕에 중립 카드를 적용한다.
- 원문 창: 핵심 메타를 먼저 표시하고 추가 메타·일정·공수는 펼쳐 볼 수 있게 한다. 본문과 이력, 복사할 원문은 보존한다. Notion·비구조화 원문에는 Mantis 접기 규칙을 적용하지 않는다.
- 전체 내용이 없는 조회·오류·미상 값을 임의로 채우지 않는다. 기존 조회·기간·질문·원문·복귀·포커스 동작과 API는 유지한다.
- 라이트·다크, 1512px·1024px·390px, 중첩 상세와 모달을 검증한다. 기존 변경을 보존하며 커밋은 하지 않는다.

## 기록

- 원본·로그·스크린샷: `/private/tmp/ai-detail-views-baseline/`.
- 기존 디자인 적용 요청이므로 추가 승인 없이 진행한다. 스타일은 화면으로, 상태 변화·정보 보존은 회귀 테스트로 확인한다.
- 변경 전 관련 Node 테스트 49개 통과 → 새 동작의 실패 4개 확인 → 변경 후 54개 통과. 프런트엔드 통합 검사 33개도 통과했다.
- `check.sh tests compile ruff`: 전체 3,442개 테스트 통과, 커버리지 91%, TypeScript·번들 검사와 Ruff 통과. 변경 파일의 `git diff --check`도 통과했다.
- Ego Lite에서 1512×748, 1024×768, 390×844를 확인했다. 모바일 고객사·이슈 패널·원문 창에 가로 넘침이 없고, 원문 창의 하단 동작은 뷰포트 안에 표시된다.
- 실제 고객사 목록의 5건/15건 전환, 경과일/완료예정일 정렬, 7일/30일 전환을 확인했다. 이슈 이전·다음 탐색과 원문 창 Escape 닫기 후 원래 버튼으로 초점 복귀, 패널 닫기 후 원래 이슈로 복귀도 확인했다.
- 라이트·다크에서 카드·본문·메타 대비를 확인했다. 추가 정보와 일정은 기본 접힘이며 펼친 뒤 원래 필드를 확인할 수 있다.
- 작업 전 복사본과 이번 변경을 직접 비교했다. 고객사 표·카드, 원문 표시 순서·접기, 이슈 권장 행동 순서, 전용 CSS·캐시 버전과 회귀 테스트만 변경했으며 API와 원문 데이터는 유지했다.
