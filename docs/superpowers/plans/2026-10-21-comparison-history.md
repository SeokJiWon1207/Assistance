# 비교 사례의 본문 처리 이력과 실험 조건 검증

사용자의 이번 수정·재검증 요청을 사양으로 삼고 메인 에이전트가 직접 수행한다.

목표: 본문에 적힌 실패 시도·소스 전달·추정적 완료를 비교 근거와 최종 답변에 보존하고, 진단용 실험 조건을 확정 원인으로 승격하지 않는다.

구조: 기존 기술 조치와 별개로 출처가 결속된 처리 이력을 추출한다. 본문과 노트의 실패·전달·불확실한 결과를 모든 비교 사례에 표시하고 요약 모델에도 전달한다. 실험 조건은 규칙·모델 선택 양쪽에서 원인 제외 검사를 공유한다. 새 모델 호출은 추가하지 않는다.

제약: 집계·조건 해석과 기존 원문 갱신 예산은 유지한다. 기존 다른 작업의 변경 파일은 수정·배포 범위에 포함하지 않는다. 비밀값·원천 DB·런타임 자료는 Git 제외 경로에 둔다. 이번 요청에 없는 커밋·푸시는 수행하지 않는다.

- [x] #25656의 본문 이력 누락과 #8634의 실험 문단 선택 오류를 실패 테스트로 재현한다.
- [x] 본문·노트 처리 이력을 출처와 함께 보존하고 조치·해결 완료와 구별한다.
- [x] 모델이 실험 문단을 선택해도 원인에 들어가지 않도록 검증하고 정상 진단은 보존한다.
- [x] 요약의 이력 누락·완료 과장 검사를 추가하고 표 대체 경로도 검증한다.
- [x] 전체 결정형 검사 후 운영 기준본과 수정본에서 같은 고정 질문을 실행한다.
- [x] 수정에 쓰지 않는 G9(기본 3+후속 6)를 최종 내용·근거·조건·시간으로 수동 대조한다. G를 수정에 쓰면 개발용으로 전환하고 별도 질문을 고정한다.

검토 초점: 실패 후 전달이 이어지는 복합 문장, 같은 날짜의 본문 이력, ‘처리된 듯’과 행정 종료, 조건 실험 뒤 별도의 확정 진단, 한 사례의 근거가 다른 사례에 섞이는 경우, 모델 분류·요약 실패 시 이력 보존.

G9는 구현 전 runtime/comparison_history_20261021/holdout.json에 고정한다. 응답시간은 감사 기록의 해석·실행·검증을 포함한 동일 지표로 비교하고, 원천 세대와 모델·검색 대체 경로를 함께 기록한다.

G에서 문단이 나뉜 실험 결과의 미확정 원인 분류도 확인하여 개발용으로 전환했다. 이후 별도 H9를 고정했고 코드 수정에는 사용하지 않았다. R1 회귀에서 비교 사례의 중복 종료 이력이 기준 건으로 보이는 표시를 발견해 이슈 번호를 명시하는 테스트와 수정도 추가했다. 최종 릴리스에서 H9와 R1~R4를 다시 실행했고, 원래 오분류 대상이 후보에서 빠져 보조 R5로 직접 포함시켜 검증했다.

최종 H9는 내용·근거 기준5건 충족/4건 미흡이다. 목표 결함 제거와 전체 답변 품질을 구별하며, 자연 요약 대체·기존 질문 지연 증가·잔여 누락과 라우팅은 평가 보고서에 남겼다.
