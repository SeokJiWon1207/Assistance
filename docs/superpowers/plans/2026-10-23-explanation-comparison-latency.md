# 설명·유사 비교 지연 개선

사용자가 승인한 범위는 응답시간 원인 확인과 개선, 현재 답변 정확도·근거·집계·조건·긴 대화 보존의 유지다. 기존 미커밋 작업을 포함한 별도 소스 복사본을 기준으로 사용한다. 서브에이전트는 사용하지 않는다.

1. 실제 모델 호출별 시간·입출력 크기·재시도 사유를 대조한다. 소스 조회와 생성·검토 시간을 구분한다.
2. 같은 의미를 반복 출력하는 선택 JSON을 축약해도 기존 서버 검증으로 확장되게 한다. 필수 질문 항목을 명확히 전달하고 독립 의미 검토·노트 보강·전체 이력은 유지한다.
3. 비교 계획 재시도와 분류·결론 생성의 중복 입력을 확인하고, 근거와 안전한 완료 판정을 유지하는 범위만 개선한다. 모델/검증 호출을 단순 생략하거나 시간을 짧게 잘라 성능을 주장하지 않는다.
4. 개발 재현 질문과 분리한 동결 새 질문·후속 질문을 같은 원본 세대로 전후 실행한다. 수정에 참고한 질문은 개발용으로 옮기고 다른 질문으로 대체한다. 전체 답변을 원문과 직접 대조하고 집계는 독립 계산한다.
5. 긴 대화 저장·복원·복원 후 질문과 전체 품질 검사를 수행한다. 반복 측정과 모델 변동의 한계를 포함해 결과를 문서화한다. 커밋·배포는 이번 범위에 포함되지 않는다.

검증 결과: 최종 새 20턴을 전후 각 2회 실행했다. 설명 7.67→6.71초, 비교 10.75→9.85초. 비교 분류 배열 실험은 누락 때문에 제외하고 기존 이름 키 형식을 유지했다. 집계·조건·166개 대화와 복원 후 0→2건 후속은 유지됐다. 새 답변 완성도는 전후 충족 8·부분 9·미흡 3으로, 기존 정확도 문제가 남아 있음을 보고서에 명시했다. 최종 결과는 docs/evaluations/2026-10-23-explanation-comparison-latency.md에 기록했다.
