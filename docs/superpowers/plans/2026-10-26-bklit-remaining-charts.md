# 남은 차트 Bklit 전환

기존 코드/데이터 및 Bklit 고정 원본을 재사용한다. 같은 codex 브랜치에서 직접 작업하고 기존 변경을 보존한다. 커밋·운영 배포는 범위에 포함하지 않는다.

- [x] 1. 대화 공수: `charts.js`, `frontend/src/charts.tsx`, `chart_models.js`. 공수 소수점과 총합, 원문 제목, 0건/부분 조회 보존. 기존 SVG는 실패 시 대체 표시.
- [x] 2. 월별 추이: `trend_chart.js`, 공통 React 래퍼. 등록건수/전달 공수 탭, 범례 선택, 기간·유형별 실제 수치 유지. 등록일/고객사전달일을 탭에 맞게 표시. ECharts 런타임 연결 제거.
- [x] 3. 관리자: `admin.js`. 실패 유형·피드백 사유·답변 방식·모델·검사 항목을 같은 Bar로 교체. 집계 API·권한·필터 유지.
- [x] 4. 수명주기: 대화/관리자 재렌더 전 루트 해제, 완료 후 마운트. 빈 값/부분 데이터/실패 대체·긴 라벨·반응형 확인.
- [x] 5. `check.sh` 테스트/정적 검사 및 실제 저장본·브라우저 비교. 기존 보관 개수 테스트 실패는 별도 기록.

판단: 월별 원본에서 누락된 셀은 0으로 만들지 않고 표의 ‘미확인’으로 유지한다. 원본 Line이 누락 구간을 안전하게 그리지 못하면 해당 상태는 수치 표로 표시한다.
판단: 관리자는 권한을 올려 검증하지 않는다. 로그인된 관리자 세션이 없으면 실제 로컬 집계 + 동일 컴포넌트 검증과 접근 제한을 구분해 기록한다.


## 2026-10-26 검증 기록

- 원본 Bklit 파일과 해시를 유지하고 서비스 어댑터만 변경했다. 관리자 SVG 아이콘 스타일이 차트까지 적용되던 충돌을 수정했다.
- `check.sh compile shell ruff mypy` 통과. Bklit 전용 Node 10개 통과. 전체 테스트 2,465개 중 2,464개 통과, 기존 배포 보관 개수 테스트 1개 실패(`RELEASE_KEEP=1` 기대, 현재 정책은 3). 차트 작업에서 보관 정책을 변경하지 않았다. 커버리지 89%.
- `check.sh audit` 통과: Python 기존 허용 예외 5개, npm 취약점 0개.
- 실제 저장본 대조: 개인 9월 공수 9.45, 순위 10행, 월별 120셀, 감사 로그 500건 일치. 실제 브라우저 월별 payload 60셀도 서버 출력과 일치했다.
- 관리자 로그인 후 품질 현황·감사 로그·답변 피드백 확인. 실제 개인 공수 답변, 월별 탭·범례·수치 표, 새로고침 후 저장된 차트 복원 확인.
- 390×844 월별 차트·범례 및 관리자 피드백 화면 확인. 이후 Mac 잠금으로 관리자 나머지 모바일·태블릿·다크 모드 최종 시각 검증이 중단됐다. 잠금 해제 후 이어서 확인해야 한다.
- 기존 서버/데이터 문제: 로컬 월별 인덱스 31,029건의 최신 등록일이 2026-08-19이다. 개인 공수용 최신 원본 저장본은 31,310건으로 별도다. 월별 9·10월의 0을 최신 실제 업무 0으로 해석하면 안 된다. 팀 범위가 ‘전사’로 표기되고, 월별 답변은 원문 근거 검증 실패 또는 복합 질문의 총 공수 검증 차단이 발생한다. 차트는 서버 수치를 유지했으며 이 문제들을 숨기지 않았다.
- 증거: `assistant_web/runtime/bklit_remaining_20261026/`. 커밋·운영 배포하지 않았다.


## 2026-10-27 재개 및 마무리

- 관리자 로그인 재시도 성공. 모바일 390×844·태블릿 768×1024 및 다크 모드 시각 검증을 마쳤다. 월별 수치 표는 표 내부에서 가로 스크롤되고 입력창 위 메시지 영역은 세로 스크롤된다.
- 폭 변경 중 SVG 음수 width 오류를 발견해 서비스 CSS에 최소 폭 및 컨테이너 조건을 적용했다. 200→390→768px 전환에서 재발하지 않으며 극히 좁은 영역에서는 기존 수치 목록을 제공한다. 원본 Bklit 파일은 유지한다.
- 개인 공수 실제 질문 재실행 결과 9.45 / 9건 / 검증 통과. 모바일 도넛·범례·막대 확인.
- 수정 후 check.sh compile ruff 및 git diff --check 통과. 기존 전체 테스트 결과와 데이터/서버 제약은 위와 같다.
- 라이트 모드·데스크톱으로 복원하고 DevTools를 닫았다. 커밋·배포하지 않았다.
