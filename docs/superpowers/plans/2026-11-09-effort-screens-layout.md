# 공수·처리시간과 화면번호 화면 개선 계획

> **For agentic workers:** `superpowers:executing-plans`로 직접 수행한다. AGENTS.md에 따라 서브에이전트를 사용하지 않는다.

**Goal:** 앞서 적용한 중립 카드·정보 위계를 공수·처리시간과 화면번호 화면에 확장한다.

**Architecture:** 기존 ES 모듈 렌더러와 이벤트 위임, CSS 표·차트를 유지한다. 공수 화면은 확인할 이슈를 먼저 두고, 화면번호는 필터·집계 범위·선택 상세를 구분한다.

**Tech Stack:** 기존 JavaScript·CSS, Node 테스트, Ego Lite. TDS와 새 의존성 없음.

**Spec:** 사용자가 승인한 앞선 두 차례의 카드·정보 위계 개선 기준을 이번 두 화면에 적용한다는 요청.

## 범위와 결정

- 공수: 기존 5개 지표를 유지하고 장기 이슈 목록을 바로 아래 배치한다. 최초 5건 표시, 조회된 목록 전체 펼치기 제공. 분석은 그 아래 2열 카드로 정리한다.
- 장기 미종료는 주황으로 표시하고, 공수·처리일 계산 기준과 기존 집계는 유지한다.
- 종료 데이터가 없는 주간 차트와 부분 조회의 빈 결과는 상황에 맞는 안내를 제공한다.
- 화면번호: 매체·고객사 필터를 독립된 카드로 분리하고 초기화를 제공한다. 화면번호가 있는 이슈·집계 화면 수·제외된 이슈를 기존 summary로 보여 준다.
- 급증은 중립 카드 안의 상태 배지로 표시한다. 히트맵에는 색상 범례와 선택 안내를 제공한다.
- 선택 상세는 요약·최근 이슈·고객사·플레이북으로 읽는 순서를 정리한다. 좁은 화면에서 화면번호를 선택하면 해당 상세로 이동한다.
- 표와 상세의 모바일 배치, 라이트·다크를 확인한다. 기존 변경을 보존하며 별도 커밋은 하지 않는다.

## 검토 조건

- 공수 펼치기는 재조회 없이 조회된 이슈를 모두 보여 주고 접을 수 있다.
- 종료 데이터가 없는 주와 당일 처리(0일)를 구분한다. 부분 조회의 빈 결과를 확정된 0건으로 표현하지 않는다.
- 화면 필터 초기화는 매체·고객사를 함께 해제하고 새 결과의 유효한 화면을 선택한다.
- 넓은 화면에서는 행 선택 포커스를 유지하고 좁은 화면에서는 선택 상세를 바로 읽을 수 있다.
- 기존 기간 변경·필터·상세·대화 질문 생성, HTML 이스케이프를 유지한다.
