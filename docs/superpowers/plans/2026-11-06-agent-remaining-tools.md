# 남은 결정형 기능의 에이전트 도구 연결

사용자가 선택한 하네스 개선 2번을 진행한다. 기존 근거·조건·수치 검증 및 전송 정책을 유지한다. 배포·서버 재시작은 포함하지 않는다.

1. 현재 코드·설정을 비교용 before로 보존한다. 다른 작업의 변경을 after에 섞지 않는다.
2. Notion 건수·목록 도구는 확정 조건과 검색 엔진을 사용한다. 전체 건수 완료와 표시 창 완료를 구분하고, 속성 도구는 현재 접근과 속성 페이지네이션을 확인한다.
3. 공수·주간·월간 보고서를 읽기 전용 도구로 연결한다. 보고서 종류·공수 방식은 검증된 계약에 묶고 기존 계산·최종 검증기를 재사용한다. 기간별 계산에도 나머지 필터를 보존한다.
4. 최근/최신 N건 모집단을 도구 인자와 계약에 명시한다. 기존 API 창 수집기를 재사용하며 필터 적용 전 모집단과 표시 개수를 분리한다. 미완료는 확정 총계로 반환하지 않는다.
5. 조건 누락·변조, 0건/미완료, 속성 접근 실패, 보고서 필터, 모집단 순서를 회귀 검증한다. 라우팅 fixture와 사용 문서를 갱신한다.
6. check.sh로 오프라인 회귀와 정적 검사를 실행한다. 유효한 동일 저장본에서 변경 전후 한투 복합 질문을 각 3회 실행하고 조건·건수·순번·본문 근거·후속 질문을 비교한다.

숫자와 보고서 본문은 서버 계산 결과로 작성한다. 공통 응답 합성 방식 변경은 후속 단계로 남긴다. 이번 단계에서는 모델이 도구 실행 순서와 추가 원문 조회를 선택한다.

완료: 1~6을 구현·검증했다. 실제 한투 복합 질문은 변경 전후 각각 3회와 Notion 속성 보완 후 최종 코드 1회를 확인했다. 전체 회귀 3,221건과 compile/shell/ruff/mypy가 통과했다. 결과와 제한은 `docs/evaluations/2026-11-06-agent-remaining-tools.md`에 기록했다.
