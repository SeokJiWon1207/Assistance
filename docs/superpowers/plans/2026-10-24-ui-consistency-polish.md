# UI 일관성과 정보 계층 개선 계획

> 수행: 메인 에이전트가 executing-plans 방식으로 순서대로 구현한다. 서브에이전트와 자동 커밋은 사용하지 않는다.

**목표:** 사용자가 승인한 순서(컴포넌트 통일 → 글자·여백 → 테두리 축소 → 핵심 행동 강조)로 기존 AI 비서 UI를 다듬는다.
**구조:** 기존 정적 JS/CSS와 마지막에 로드되는 design_system.css를 유지한다. 실제 데이터·API·권한·검색 의미는 변경하지 않는다.
**기술:** FastAPI, Vanilla JS/CSS, 기존 Node 테스트 및 check.sh.
**기준:** 첨부 PDF, 토스 스타일 비교 후 사용자의 ‘차례대로 진행’ 지시.

## 제약과 결정

- PDF의 배지 6px, 버튼 8px, 카드 12px, 입력창 16px 유지. 필터 칩은 pill을 유지한다.
- 현재 브랜드 파랑과 접근성 대비를 유지한다. 토스 색상을 그대로 복제하거나 프레임워크를 교체하지 않는다.
- 앞선 정확도 수정(커밋 전 변경)은 보존한다.
- CSS 외관 변경은 브라우저 계산 스타일·스크린샷으로 확인한다. 동작이 바뀌는 복사 버튼은 기존 이벤트·접근성·대상 답변을 검증한다.
- 기존 메뉴와 정보는 숨기지 않는다. 경고·부분 조회·실패 안내는 강조를 보존한다.
