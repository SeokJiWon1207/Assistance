# 분석 중심 AI 비서 UI 구조

사용자가 2026-11-10 승인한 `analytics-redesign.html` 시안을 main의 실제 UI에 적용한다. 기존 TDS 도입 없이 JS/CSS와 Bklit 차트 모듈을 사용한다.

- 전체 현황: 스파크라인 지표 → 전체 폭 유입·고객사 전달 추이 → 상태 분포·순위 → 관련 이슈. 상시 오른쪽 알림 레일은 제거한다.
- 비교 분석: 같은 길이의 이번/직전 기간 등록 추이와 고객사·화면번호·담당자별 비교. 기존 공수·화면번호 상세로 연결한다.
- 처리 흐름: 실제 현재 상태 단계, 등록 주차 × 현재 상태 행렬, 경과일 분포. 과거 상태 이력이 없는 데이터로 전환율·과거 잔존율을 생성하지 않는다.
- 고객사: 비교 표·주별 등록 행렬을 중심으로 바꾸고 상세는 추이·분포를 목록보다 먼저 표시한다.
- 내 업무: 확인·진행·검증·종료 단계의 칸반. 알 수 없는 상태는 별도 표시하고, 최근 수정된 해결·종료 업무는 완료일로 오인하지 않도록 범위를 명시한다. 드래그로 원천 상태를 변경하지 않는다.
- 지표·차트·목록에 동일 고객사 선택을 적용한다. 현재 미종료는 선택 기간 신규가 아닌 현재 전체 미종료다.
- 부분 조회는 최소 건수/미확정으로 표시하고, 불완전한 분모의 비율·증감률을 확정하지 않는다. 이슈 원문·질문·기간·정렬·검색·상세 복귀 기능을 보존한다.

시안의 기간 내 완료는 실제 원천에 있는 고객사전달일 기준의 **고객사 전달**로 구체화한다. 해결·종료의 최종수정일은 정확한 완료 이력이 아니므로 신규 차트의 완료 이벤트로 쓰지 않는다. 정확한 과거 잔존율·단계 도달 전환율은 후속 상태 이력 연동 대상이다.
