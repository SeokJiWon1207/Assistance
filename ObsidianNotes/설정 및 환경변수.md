# 설정 및 환경변수

## `.env` (assistant_web/.env, `.env.example` 기준)

```bash
# 회사 LLM 모델
COMPANY_MODEL_46_API_KEY=
COMPANY_MODEL_46_ENDPOINT=http://.../v1/chat/completions
COMPANY_MODEL_46_EXPIRES_AT=2026-12-31

# Mantis
MANTIS_API_TOKEN=
MANTIS_API_URL=http://.../mantis/api/rest/issues

# Notion
NOTION_API_TOKEN=
NOTION_DATABASE_IDS=
NOTION_API_VERSION=2022-06-28
NOTION_FETCH_PAGE_BLOCKS=true

# 모델 히스토리/타임아웃 튜닝
MODEL_HISTORY_MAX_MESSAGES=20
MODEL_TIMEOUT_SECONDS=180
FOLLOWUP_REWRITE_TIMEOUT_SECONDS=20

# 정확도 검증 Slack 알림
SLACK_WEBHOOK_URL=
ACCURACY_CHECK_QUESTIONS=10
```

## `config/models.json`

프론트엔드에는 모델 이름/상태/만료일만 노출, endpoint와 key는 백엔드 전용.

```json
{
  "id": "company-46",
  "label": "회사 모델 46",
  "model": "46",
  "endpoint": "http://59.6.135.38:13025/v1/chat/completions",
  "apiKeyEnv": "COMPANY_MODEL_46_API_KEY",
  "expiresAt": "2026-12-31",
  "enabled": true
}
```

## 검색 파이프라인 관련 설정

```bash
QUERY_PLANNER_ENABLED=true
NOTION_TOOL_TIMEOUT_SECONDS=12
NOTION_TOOL_MAX_RETRIES=0
```

## 기타 설정 파일

- `config/mantis_filters.json` — 질문 키워드 ↔ Mantis 저장 필터 매핑 → [[Mantis 연동]]
- `config/customer_aliases.json` — 고객사 별칭 → [[Mantis 연동]]
- `config/evaluation_cases.json` — 검증 센터 기준 질문과 기대값

## 보안 메모

- `.env`, `deploy/aws/Assistance_Key.pem` 등 시크릿 파일은 git에 커밋하지 말 것 (`.gitignore` 확인)
- EC2 배포 시 `INCLUDE_ENV=1`로 토큰이 서버에 올라가므로 보안 그룹 범위를 제한할 것 → [[배포 - AWS EC2]]
