# 백엔드 구조

← [[00 Home]] · 관련: [[아키텍처 - 검색 파이프라인]] · [[API 엔드포인트]]

## 조립과 진입점

| 경로 | 역할 |
|---|---|
| `backend/main.py` | FastAPI 생성, 미들웨어, 라우터와 정적 파일 조립 |
| `backend/app.py` | 기존 `backend.app:app` 실행을 위한 하위 호환 진입점 |
| `backend/api/` | chat, notion, search, quality, operations API 라우터 |
| `backend/services/chat_service.py` | 질문 해석 → 검색 → 결정형/모델 답변 → 검증 오케스트레이션 |

## 도메인과 외부 소스

| 경로 | 역할 |
|---|---|
| `backend/understanding.py` | 자연어 제약조건, 검색 의도, 후속 질문 해석 |
| `backend/query_planning.py` | QueryPlan 생성·검증·보정 |
| `backend/retrieval.py` | Mantis·Notion·Chroma 검색 단계 조합 |
| `backend/answers.py` | 결정형 목록·건수·상세 답변 |
| `backend/sources/` | Mantis, Notion, Chroma 외부 소스 어댑터 |
| `backend/reports/` | 공수·검증·A/B·정확도 리포트 |
| `backend/audit.py` | 감사 로그 DB와 채팅 스트림 컨텍스트 |

의존 방향은 `main → api → services → domain/sources`다. 테스트와 스크립트는
`backend.app`의 재노출 이름을 사용하지 않고 실제 함수 소유 모듈을 직접 import한다.

## 프론트엔드

`backend/static/index.html`, `app.js`, `frontend_core.js`, `styles.css`로 구성된 단일 페이지다.
`frontend_core.js`의 대화 저장·히스토리·SSE 파싱은 Node 테스트에서 독립 검증한다.
