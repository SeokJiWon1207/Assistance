# 백엔드 구조

← [[00 Home]] · 관련: [[아키텍처 - 검색 파이프라인]] · [[API 엔드포인트]]

## 파일

| 파일 | 역할 | 크기 |
|---|---|---|
| `backend/app.py` | FastAPI 앱, 라우트, 검색/답변/감사 로직 대부분 | ~7,183줄 |
| `backend/query_planning.py` | QueryPlan 검증/보정 | ~236줄 |
| `backend/tools/mantis_snapshot.py` | Mantis 스냅샷 조회 헬퍼 | ~86줄 |
| `backend/static/` | 프론트엔드 (index.html, app.js, styles.css) | — |

> `app.py`가 라우트·설정 로딩·질의 파싱·검색·감사 로그까지 대부분을 담당하는 단일 모듈이다. 기능 단위로 쪼갤 여지가 있어 보이지만 현재는 통합되어 있다.

## `app.py` 안의 주요 영역 (대략 줄 번호)

- **설정/환경 로딩**: `load_dotenv`, `get_model_registry`, `get_mantis_settings`, `get_notion_settings` (43~530줄대)
- **질의 이해**: `is_follow_up_question`, `resolve_reference_from_context`, `rewrite_follow_up_query_with_model`, `extract_query_constraints` 등 — 자연어 질문에서 고객사/기간/담당자/상태 등 제약조건 추출
- **QueryPlan 처리**: `merge_query_plan_constraints`, `plan_search_intent_with_model`, `should_use_intent_planner`
- **라우트**: 파일 끝부분 6585~7183줄에 전부 모여 있음 → [[API 엔드포인트]] 참고

## 프론트엔드

`backend/static/index.html` + `app.js` + `styles.css`로 구성된 단일 페이지. 별도 빌드 도구 없이 서버가 정적 파일로 서빙.
