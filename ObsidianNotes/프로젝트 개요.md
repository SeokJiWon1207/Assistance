# 프로젝트 개요

← [[00 Home]]

## 목적

회사 LLM API를 직접 호출하는 **컨텐츠서비스 대화형 웹앱**. 사용자가 자연어로 질문하면 근거(Mantis 이슈, Notion 페이지)를 찾아 답변한다.

## 리포지토리 구조

```
Assistance/                     # 루트 (git 저장소 아님)
├── scripts/
│   └── make_vector_db.py       # Mantis → ChromaDB 로컬 인덱스 구축/갱신
├── data/
│   ├── mantis_chroma_db/       # 현재 ChromaDB 벡터 스냅샷
│   └── backups/                # 이전 스냅샷 백업
├── ObsidianNotes/              # 프로젝트 문서 볼트
└── assistant_web/
    ├── backend/
    │   ├── app.py               # FastAPI 앱, 라우트, 검색/답변 로직 전체
    │   ├── query_planning.py    # QueryPlan 검증/보정
    │   ├── tools/mantis_snapshot.py
    │   └── static/               # 프론트엔드 (index.html, app.js, styles.css)
    ├── config/                    # 모델·필터·고객사·검증 설정
    ├── scripts/                   # 정확도 검증과 로컬 실행 도구
    ├── tests/                     # 자동 테스트와 수동 검증 질문
    ├── runtime/                   # 감사 DB와 정확도 리포트
    ├── deploy/aws/                # EC2 배포 스크립트
    ├── artifacts/                 # 생성된 배포 산출물
    └── .env                        # 시크릿 (API 키, 토큰)
```

## 핵심 개념

- **[[Mantis 연동|Mantis]]**: 회사 이슈 트래커. 구조화 필터, 저장 필터 API, 페이지 스캔, ChromaDB 유사도 검색 4가지 방식으로 조회.
- **[[Notion 연동|Notion]]**: 이슈리스트/주요이슈현황 데이터베이스를 공식 API로 직접 조회.
- **QueryPlan**: LLM이 질문을 구조화된 실행 계획(operation, 소스, 필터, 정렬)으로 변환하고, 코드가 재검증/보정한 뒤 실행.
- **감사 로그**: 질문 의도 → 적용 필터 → 조회 근거 → 계산 → 최종 답변까지 단계별 검증.
- **[[정확도 자동 검증]]**: 매일 실제 데이터로 재현 가능한 질문 10개를 만들어 답변을 자동 채점.
