# 정확도 자동 검증

← [[00 Home]] · 관련: [[프로젝트 개요]]

## 목적

`scripts/accuracy/dynamic_accuracy_check.py`가 실제 소스 데이터에서 재현 가능한 질문 10개를 만들어 실제 채팅 엔드포인트(`/api/chat`)에 질의하고, 독립적으로 조회한 Mantis/Notion 스냅샷과 답변 ID·제목·건수를 비교한다.

```bash
cd assistant_web
python3 scripts/accuracy/dynamic_accuracy_check.py --questions 10
```

- 매일 시드가 바뀌어 표본 레코드는 달라지지만 재현 가능
- 결과는 `runtime/accuracy_reports/`에 JSON + Markdown으로 저장
- 종료 코드가 0이 아니면: 질문 1개 이상 실패 / 연동 불가 / 요청 개수만큼 질문 생성 실패

팀 검증용 질문 예시와 해석 기준: `assistant_web/tests/test_questions.md`

## Slack 알림 자동 실행

`scripts/accuracy/run_accuracy_check_and_notify.py`는 검증을 실행하고 **통과 실패(fail/경고) 시에만** Slack 알림을 보낸다. 그리고 매 실행마다 결과 요약을 Obsidian 볼트에도 자동으로 남긴다.

```bash
cd assistant_web
python3 scripts/accuracy/run_accuracy_check_and_notify.py
```

### 설정

```bash
SLACK_WEBHOOK_URL=https://hooks.slack.com/services/xxx/yyy/zzz
ACCURACY_CHECK_QUESTIONS=10   # 선택: 하루 검증 질문 개수 (기본 10)
OBSIDIAN_VAULT_PATH=/absolute/path/to/your/vault
OBSIDIAN_ACCURACY_FOLDER=Automation Reports/Mantis Notion
```

- `OBSIDIAN_VAULT_PATH`가 비어 있으면 기본 후보 볼트를 자동 탐지
- 저장 노트에는 실행 시각, 전체 점수, Mantis/Notion 통과 수, 실패 문항, 직전 대비 점수 변화 포함

### crontab 등록 (수동)

스크립트는 스스로 cron에 등록하지 않는다 — 스케줄 변경은 사용자가 직접.

```cron
0 8 * * * cd /path/to/Assistance/assistant_web && /usr/bin/python3 scripts/accuracy/run_accuracy_check_and_notify.py >> runtime/accuracy_reports/cron.log 2>&1
```

## 리포트 위치

`assistant_web/runtime/accuracy_reports/accuracy-YYYYMMDD-HHMMSS.{json,md}`에 실행별 결과가 쌓인다.
